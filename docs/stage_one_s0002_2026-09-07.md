# Stage-one end-to-end result: S0002

The guarded runner completed for exactly one pilot site, `S0002` (freshwater),
using the project `.venv`. It cannot be used to run the five- or 40-site stages.

Command: `.venv/Scripts/python scripts/run_stage_one.py` (Windows equivalent).

Copernicus GLO-30 was read through GDAL `/vsicurl/` from the public AWS COG.
Only a 3x3 window around the sample coordinate was requested and written to
`data/cache/stage_one_v2/S0002_copernicus_3x3.tif`; the sidecar records URL,
provider, retrieval time, CRS, EGM2008 datum, 30 m resolution and SHA-256.
Derived metrics were elevation 308.964 m, local relief 0.886 m, and mean local
slope 0.805 degrees. No invalid cell was treated as zero.

Earth Engine initialized with project `stickleback-507923` and sampled
`MERIT/Hydro/v1_0_1` at 90 m: `elv=310.700`, `dir=8`, `upa=0.006016 km2`,
`upg=2`, `hnd=5.100 m`, `wat=0`, and `wth=null` (masked). No raster export or
global MERIT download occurred. Catchment status remains
`no_hydrology_data`/`not_implemented_no_delineation` by design.

The processed one-row artifact is
`data/cache/stage_one_v2/S0002_processed.json`. Live services are not required
by tests; the existing fixture/mocking tests cover invalid/no-data handling.
