# Earth Engine pilot validation viewer

The viewer sources and deployment instructions live in
[earth_engine_validation](earth_engine_validation/README.md).

- `ee_pilot_validation_app_current.js`: current registry-based viewer.
- `ee_pilot_validation_app.js`: reusable template with placeholder asset IDs.
- `ee_pilot_validation_app_v3.js`: pinned historical release for reproducibility.

The former `apps/ee_pilot_validation_app.js` was an exact copy of the template
and has been removed. Use the canonical file in `earth_engine_validation/`.
